## ✨ Features

* 🎨 **Modern Futuristic UI**: Cyberpunk-inspired dark aesthetic with custom emerald/cyan gradients and glassmorphic cards.
* ⚡ **Fluid Animations**: Smooth scrolling, cursor-interactive avatar with spring physics, and Framer Motion micro-interactions.
* 📱 **Fully Responsive**: Optimized for ultra-wide monitors, laptops, tablets, and smartphones.
* 📄 **Integrated Documents**: Direct access to downloadable Resume and Cover Letter PDFs.
* 🧩 **Modular Architecture**: Built with clean, reusable components and TypeScript type safety.
* 📊 **JSON-Driven Content**: All portfolio data is centralized in `portfolio/src/data/portfolio.json` for effortless maintenance.

## 🚀 Getting Started

To launch the project locally:

```bash
# 1. Navigate into the portfolio directory
cd portfolio

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the portfolio.
