## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/AkshayKod/portfolio.git
```

### 2️⃣ Navigate to the Project Folder

```bash
cd portfolio
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start the Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:5173
```
